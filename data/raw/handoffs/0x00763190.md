## What had to be spelled exactly (all measured)

1. **`GetAnimation()` is a virtual call at vtable +0x1b4.** A `__thiscall` function-pointer type
   (`typedef CAnim* (__thiscall* F)(void*)`) reproduces
   `mov eax,[edi]/mov edx,[eax+0x1b4]/mov ecx,edi/call edx` exactly. VC8 accepts `__thiscall` on a
   pointer type even though it refuses it on a free function.
2. **The p (queue-record ready) computation needed THREE separate shapes at once**, and the last
   of them was found only by sweeps (38 variants):
   * the first null test must be the *plain member* (`!h->task->unk20`), so MSVC folds it into
     `cmp dword [eax+0x20],0` and then *re-loads* it (`mov eax,[eax+0x20]`) for the third term;
     with an accessor for both, the compiler CSEs into `mov/test` and the function is 6 bytes short;
   * `p` must be an **`int`** (not `bool`), so the inlined comparison materialises as
     `xor eax,eax / cmp / sete al`;
   * the fields must be read **through `volatile` casts** and through two one-line accessor members
     (`GetFinished()` / `GetTotal()`), which is what finally produced
     `mov ecx,[eax+8] / mov edx,[eax+0x10] / xor eax,eax / cmp ecx,edx / sete al`
     (any non-volatile spelling folds the second operand into the `cmp` and loses 4 bytes);
   * the test is `if ((char)p)` - `if (p)` gives `test eax,eax`, `(char)` gives the original's
     `test al,al`.
3. `FUN_00763190` is a `__thiscall` member (`this` in ecx, `ret 4`).

### The measured rule (pack compiler, VS2005 SP1, /O2) - why this shape is not source-reachable

Micro matrix (out/00763190/micro4,5,6,7,8,9,10,11,12.py; ~50 shapes in 0.2 s TUs):

| this operand | argument kind | emission |
|---|---|---|
| register (esi, live across a call) | memory global | `mov ecx,[g] / push ecx / **mov ecx,esi** / call` |
| register (esi) | call result | `... add esp,0x10 / **push eax** / mov ecx,esi / call` |
| register (esi) | real 2-arm phi of a call result | `... add esp,0x10 / **push eax** / mov ecx,esi / call` |
| memory (stack param) | call result | `mov ecx,[esp+0x14] / add esp,0x10 / push eax / call` |
| memory (stack param) | any | `mov ecx,[esp+4] ... push` - load lands BEFORE the push |

So VC8 emits **argument pushes before the this-copy whenever the receiver is register-resident**, and the
"this-load before the push" cases are all *memory-operand* receivers whose load got scheduled into the arg setup -
those print as `mov ecx,[mem]`, never `mov ecx,edi`. A real x86 phi does **not** defer a `push` (only x87 stores
defer, which is what §19.66 measured on 0x00575a30). No free phi exists here either: the only enclosing branch is
`if (h->equip)`/`if (animation)` and defining the argument in both arms costs a second call.

Corollary: any spill/reload spelling changes the push operand to `push [esp+X]`, so it cannot match `push eax`.

Pack-level: 8 R4 shapes (bool-valued result, nested if, `!= 0`, comma-assignment, `== false`, `(void*)` cast,
`!(!= false)`, control) -> all extent 523 with the identical pair (out/00763190/sweep2.py, v/).
`--permute --trials 400 --jobs 4`: no match, best score 23 (= baseline).

### Verdict
