## Next ideas
The last delta is the register *pair* (tid, spin): the original is tid=edi, spin=ebx and the
zeroing is in the else path. Our compiler gives that pair only when the counter is initialized
before the branch (then the `xor` is hoisted), and puts the zeroing in the else only when the
tid is declared first (then tid takes ebx, spin edi). So the original probably has a **third**
value that pins the pair, or the counter is a different variable than the CAS comparand: try
`unsigned int uiExpected = 0; ... if (g_pfnCas(&owning, tid, uiExpected))` declared after the
branch together with the counter declared on top, or a `bool`/`char` third value that forces
ebx to the counter. Also try declaring the counter as `unsigned long` / `DWORD`.
