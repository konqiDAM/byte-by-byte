## Hypotheses for the next agent (in the order I would try them)

1. **The pointer operand in the original is not the plain local.** The sibling comparison says the
   shape, not the spelling, is wrong. Try making `name` reach the expression through a load that
   the compiler cannot promote, while keeping the rest of the function byte-identical — that is the
   only micro shape observed to flip the SIB. Nothing in the current draft's byte stream loads it,
   so this most likely means the *whole* name handling differs (e.g. the original reads the name

   rest of the function happens to encode identically.

   e.g. `dir`, is the only array in the frame; the extension is taken from `name`).
3. If a permuter is available: **the SIB byte is the only degree of freedom left** — a search that
   only needs to flip one byte of encoding, everything else fixed, is exactly what a longer
