## What the screen does not tell you

`call [0xe0001000]` is **not** a binding problem. A reloc-masked byte compare of the compiled object against
the image (`tmp\cmp59ed00.py`) shows 17 differing bytes, all one 4-byte instruction shifted by 24 bytes
(`mov edi,[esp+0x4c]`: mine +0x43, original +0x5b). f3check's four `SECREL target outside the image` errors
come from its derive-from-original path reading the *shifted* bytes at the TLS relocation offsets; they vanish
when the shift is fixed. Do not chase the import declarations: they are the same ones the pack's matched
neighbours use (`unit_1d0141954eff.cpp` line 11044 etc.).

## Hypothesis for the next attempt

The original has esi=this, edi=model, ebx=thread block, **ebp=saved tag**, and the tag's web spans
+0x43..+0x474 across every call (the cold exit does `mov [ebx+0x298],ebp`). So the fix is to make the saved
tag stay in a callee-saved register *while* the model read is emitted at +0x5b. Untried levers:
1. an extra *use* of the saved tag in a hot block (raises its cost above the live-range-split threshold);
2. a context whose saved value escapes (address taken once) so it cannot be split;
3. raise the final register pressure so ebp cannot be reused as the zero constant;
4. a two-member context (block + tag) once a way is found to express the thread block without an extra `lea`.

## What is now known (use this, it replaces guessing)

1. The load position comes from a **may-alias link created by the inlined constructor's stores**. With
   plain `local = x` stores the scheduler hoists `mov edi,[esp+0x4c]` to +0x49; with the stores inside
   the inlined `AutoMemContext` ctor the load waits behind them and sits at **+0x5b** exactly as the
   original does. So the original source is RAII *then* read: family B is the correct structure.
2. The wall is the **saved tag's live range**, not the load. In A the tag is defined while edi (model) is
   already live, takes **ebp**, is never split, and the cold exit restores it from the register
   (`mov [ebx+0x298],ebp`, +0x474) — the original. In B the same tag is **split**: **edx**, spilled to
   `[esp+0x14]`, reloaded at both exits (`mov eax,[esp+0x14]` / `mov ecx,[esp+0x14]`); ebp is then free
   and the **constant-0 promotion** claims it (`xor ebp,ebp`, then `cmp edi,ebp`, `cmp ecx,ebp`,
   `cmp ebx,ebp`, `mov [esi+0x38],ebp` ...), which is the whole 842-byte cascade. 1163 = 1168 - 5 from
   the imm-0 stores the zero register makes redundant.
3. Anything that reproduces the original must stop that split (or occupy ebp before the promotion).
   Guard both: extent must stay 1168 and the colouring must stay esi=this, edi=model, ebx=block, ebp=tag.
