## What the function does (fully decoded from disasm)
Dual skinning/vertex kernel. Args: `in`=[ebp+8], `ctx`=[ebp+0xc], `outCursor`=[ebp+0x10] (float**).

- `in`: +0 `const Vec4* verts` (stride 0x10), +4 `const float* weights` (stride 8,
  reads element+4 i.e. odd floats / float2 .b), +8 `float scale`, +0xc `int count`.
- `ctx`: +4 `float param4`, +8 `float param8`, +0x30 `SkinObj* A`, +0x34 `SkinObj* B`.
- `SkinObj`: byte flag at +1 (`active`), vec3 scale at +0x30..0x38, 3x3 matrix as
  three Vec4 rows at +0x50/+0x60/+0x70 (uses .x/.y/.z of each row = columns of M).
- Loop `for (i = count-1; i >= 0; i--)` writing 0x30-byte records, `*outCursor += n*0x30`.

Per record (out = 12 floats, only first ~9 used):
1. `fld [edi]` loads v.x BEFORE the A->active test (stays on FPU through branch).
   A->active==0: copy v vec4 -> out[0..3]. Else: matmul -> out[0..2], w via `fst` (kept on FPU).
   Matmul order (partial trace): out.x ~ `v.y*r1.x + v.x*r0.x + v.z*r2.x` — column dot,
   y-term first. Same for out.y/out.z with r*.y / r*.z.
2. `fld [edi]` again + `fchs`: B->active==0: negate v -> out[4..7]. Else matmul of -v.
   (`mov esi,[ebx+0x34]` B-pointer load is hoisted into first branch region.)
3. Squares of out[0..2] and out[4..6] (six temps esp+0x20..0x38), weighted by
   A->scale and B->scale respectively, summed pairwise, `+ FLT_EPSILON`
   (1.1920928955078125e-07, the two persistent x87 stack values: fldz + fld qword eps),
   `1.0f/(sum)` -> out[3].
4. `out[7] = ctx->param8 * weights[k]` ([ecx-8] where cursor = weights+4+8k+8);
   `out[8] = ctx->param4 * in->scale`.
5. `out[0] += eps` (fadd st(1) where st1=eps), then `mov byte [rec+0], 0xd`
   — overwrites low byte of out[0] float (union/tag or deliberate bit write).
6. edx+=0x30, eax+=0x30, edi(v)+=0x10, weight cursor +=8, counter--, jns.

Early exit (count<=0): `*outCursor = out` unchanged, pop, ret.
