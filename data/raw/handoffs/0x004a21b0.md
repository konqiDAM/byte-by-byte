## Residue class

**Class 1 (§1 of the wave brief): scratch/register rotation at one site**, with a §2-class-1
mechanism — the allocator *coalesced* the unnamed intermediate (`[esi]`) with the destination
register of the next load (`ecx`). In the original the intermediate kept its own register (`eax`).
This is the "chained load reuses the destination register" preference; eax and ecx are **both free**
at 0x8e in both builds (identical bytes either side of the site, same prologue `push edi/push esi/
push ebx`, no 4th callee-saved value), so it is a pure tie broken differently.

Note the same value shape two blocks earlier is emitted **identically in both**:
`0x61 mov eax,[esi] / 0x63 mov eax,[eax+4]` (item -> form04) — so the original *does* coalesce a
temp into the destination register when the destination is a plain scratch. It declines to do so
only when the destination is the constrained `ecx` (thiscall). Ours accepts it there.
