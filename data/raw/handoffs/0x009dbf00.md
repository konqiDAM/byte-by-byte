## What is measured (exp91/disasm_orig.py 0x009dbf00 491)
* `__thiscall`, `ret 4`, one stack parameter = a `bool*` out: the two tails are
  `*out = 1` (0x1cd) and `*out = 0` (0x1dc), so the function is `void f(bool* out) const`.
* the callee is 0x00924ca0 = `hkRotation::IsOrthonormal(float) const` (the symbol table has several
  manglings for that address; the bytes say: thiscall, 2 stack params - a pointer then a float,
  callee pops 8, returns the pointer in eax). Each call site is
      push <scratch 4 bytes>; lea p,[esp+..]; fstp [esp]; push p; lea ecx,<rotation>; call
      cmp byte ptr [eax], 0 ; je <false tail>
  with the constant 0.001f from `__real@3a83126f` (0x00db7df0).
* the four call arguments are the four consecutive bytes at esp+4..esp+7 (the compiler packed four
  one-byte hkBool results into one dword), and the fourth call's `this` is the local's +0x40.
* call 1 `this` = this+0x20, call 2 `this` = this+0x60, call 3 `this` = the local at esp+8,
  call 4 `this` = local+0x40.
* the last check is `fld [esi+0xa4]; fld [esi+0xa8]; fcompp; fnstsw ax; test ah,1; jne false`
  (= `if (this->m_a8 < this->m_a4) -> false`, i.e. `a4 <= a8` required).
* before the calls the function copies a block into one stack local (base B = esp+8):
    B+0x00 float[3]   from this+0xd0..0xd8
    B+0x10 float[9]   from this+0xdc..0xfc
    B+0x34 16 bytes   from the global at 0x01092a50 (4 consecutive dwords 0x50/0x54/0x58/0x5c)
    B+0x44 float[12]  from this+0x100..0x12c
    B+0x74 16 bytes   from the same global again
  i.e. two copies of one 16-byte global object; the local looks like a by-value materialisation of
  a sub-structure that the 3rd/4th calls then take as `this`.
* frame: `and esp,-16; sub esp,0x88` plus 8 bytes of pushes (the last slot is at ebp-4, so the
  aligned frame really spans 0x8c bytes).
