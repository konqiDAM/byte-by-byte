## The whole problem

On the `load == 0` exit SP1 proves `model == 0` from the earlier branch and rewrites `return model;`
into `xor eax,eax` (ours) where the original has `mov eax,edi` (a copy). 127 of 129 bytes match.

Unlock rule found: the fold stops exactly when the load block **assigns** `model` and the return block
is shared with it (value is then a phi). That unlock costs the register colouring: with the extra uses
of `model` the allocator colours `model` before `this` (cost = uses × P × block frequency, tips §"How
the back end decides"), and with the merged tail (s05) the colours are right but the block count is one
short. Everything that produces ORIG's 3-tail layout produces the swap, and everything with the right
colours produces one tail instead of two.
