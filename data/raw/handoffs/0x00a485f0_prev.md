## Classification: class 2 (liveness / colour tie)

Not class 1: nothing rotates. `base` and `s` never interfere (`s` is loaded after
`base`'s last use), so they **coalesce into one web**, and that merged web is the
first web defined in the loop block, so it always takes `eax`; the key then takes
`ecx`, and the receiver therefore needs `lea ecx,[eax+0x28]` instead of
`add ecx,0x28`. The original has the merged web in `ecx` and the key in `eax`.

The tie is chicken-and-egg: the *schedule* decides which web dies last, and the
last-dying web takes `eax`; but the register choice also decides whether the
compiler can emit `add` (destructive, needs s already in ecx) or `lea`.
