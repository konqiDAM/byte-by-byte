## 2. THE NEW LEVER: redundant parentheses are a scheduler control (22 -> 16)

```cpp
// dot3                     22 -> 20
return ((m_quad[0] * v.m_quad[0]) + (m_quad[1] * v.m_quad[1])) + (m_quad[2] * v.m_quad[2]);
// setMul4(hkReal r, const hkVector4& v)      20 -> 16
{ m_quad[0] = (r * v.m_quad[0]); m_quad[1] = (r * v.m_quad[1]);
  m_quad[2] = (r * v.m_quad[2]); m_quad[3] = (r * v.m_quad[3]); }
```

Adding a redundant paren pair around a subexpression changes the tree this backend schedules
(inert at the front end, live at the scheduler), which moves x87 load-vs-dup ties **without
changing the instruction count**. `((x))` (double parens) is a *different* shape: 18 for setMul4,
so the exact nesting level matters. This is a general lever for this compiler — worth carrying to
other x87 residues, and it replaces the earlier conclusion "operand swaps are canonicalised away"
with "swaps canonicalise, tree *shape* does not".
