## What worked

One change, in the body at the `int state=process->state;` line (source line ~1316 of the draft):

```cpp
// before (ndiff 8)
int state=process->state;
// after (ndiff 6) — a named alias of the same pointer, used only by that load

```

It emits **no extra instruction** (the alias is folded into the existing load) but changes the
per-block value count, and it flips the 0xb9 site to the original:

```
0xb9  ORIG/OURS now both:  mov eax,dword ptr [esi+0x60]
0xbc                       mov edi,dword ptr [eax+0x28]
```

This is the "P (values used in a block) shift flips a register tie" lever from
`compiler_tips.md` §"Registers: colouring by cost", applied at a load instead of a volatile.
