## The function (fully decoded — trust this, it cost a whole session)

Havok rotation orthonormalization. ABI verified against 6 real callers (xref scan +
FUN_009e9ee0 disassembly): **MSVC private convention for a static function** —
`out`=esi (live across the sqrt calls), `src`=ecx, `d`=eax, `dt` as the one stack arg.
Caller shape: `lea esi,<local>; fstp [esp] (dt); mov ecx,<src>; call`.
Prologue `sub esp,8`, epilogue `add esp,8; ret`.

Body: `c0 = src.a + dt*d.a (4 lanes); c1 = src.b + dt*d.b; normalize4(c0);
dot = dot3(c0,c1); c1 -= dot*c0 (4 lanes); normalize4(c1); c2 = cross(c0,c1),
c2.w = the fldz 0.0 left on the x87 stack by N2's sqrt branch (stored with `fst`,
no pop); normalize4(c2)`. The dot is a **3-term dot3**; the GS subtracts all 4 lanes.
len2 in all three normalizes: loads y,x,z; squares **x² then y²**; tree
`((x²+y²)+z²)` with the inner sum landing in y²'s slot; z² computed in place
(`fmul st,st`). The cross: cy→temp0, cz→temp1, cx→direct store, then the cy/cz/w
destination stores.

## What worked (the mechanism list — reuse these)

1. `static __declspec(noinline)` + caller shim fed from volatile globals → the
   private convention falls out (out=esi, src=ecx, d=eax, dt stack).
2. **Fully inline body** (no helper functions): joins the dt value web; fixes the
   c1-lane1 addMul to `fld [eax+0x10]; fmul st(1)`.
3. **Reference locals** `V9c60& c0 = out->c0;` etc. for the multiply/GS/dot sections:
   flips the lane commutations to ORIG's load-first forms.
4. **Len2 reads through the PARAM path** (`out->c0.x * out->c0.x + ...`) while the
   rest uses references: fixed all three len2 trees (the rank sort reacts to the
   base symbol).
5. **The dot reads c1 through a LATE-declared second reference**
   (`V9c60& c1b = out->c1;` right before the dot): fixed the dot's term2 form.
6. **`_ReadWriteBarrier()` after the cross stores + the N3 len2 via the param path**:
   fixed the N3 len2's load-hoisted dance (the volatile-pointer version folds the
   squares into `fld [mem]; fmul [mem]` — wrong shape).
7. **va/vb declared in the order vb-then-va** (`const volatile V9c60* vb = &out->c1;`
   then va): fixed the cross's cx read order.
8. The cross's cy/cz as named floats or a struct — both give the cross shape
   cy→[esp], cz→[esp+4], cx→direct, exactly ORIG.
